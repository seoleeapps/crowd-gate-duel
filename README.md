# 갈림길 군중 대전 (crowd-gate-duel)

위로 달리는 코스에서 구간마다 갈림길 게이트 셋이 내려온다. 나와 상대가 3초 안에 하나씩
비공개로 고르고 동시에 공개한다. **같은 게이트를 고르면 뒤처진 쪽이 먼저 지나간다.**

이 한 줄이 제품의 전부다. 앞서 있으면 상대가 고를 칸을 피해야 하고, 뒤처져 있으면 상대가 고를
칸을 노려야 한다. 유인이 정반대라서 매 구간 상대를 읽게 된다.

상대는 실시간 접속자가 아니라 **저장된 사람의 선택 기록**이다. 코스는 시드 결정론이고 판정은
순수 규칙이라 선택 시퀀스만 있으면 대국이 완전히 재현된다. 상시 켜져 있어야 하는 서버가 없고
판당 문서 쓰기 1건과 읽기 1건이면 사람과의 대전이 성립한다.

- 만 13세 이상, 글로벌 기본(1차 언어 영어·한국어), 세로 고정, 한 손 조작
- 판 진행 중 광고 0, 승패에 영향을 주는 유료 요소 0, 에너지 없음
- 봇은 상대 기록이 없을 때만 대체하며 화면에 봇임을 표시한다

기획 문서는 `docs/game-design/` 이 원본이며 구현은 그 계약을 따른다.

## 현재 상태

프로토타입 1~2주차 범위인 **도메인 규칙 코어와 코스 생성기·검증기**가 구현돼 있다.
화면과 연출은 아직 없다.

| 인수 시나리오 | 내용 | 상태 |
| --- | --- | --- |
| AC-002 | 생성기 대량 검증 통과 | 헤드리스 테스트로 검증 |
| AC-003 | 같은 시드·같은 선택열 재현 | 헤드리스 테스트로 검증 |
| AC-004 | 고정 전략 승률 60% 이하 | 헤드리스 테스트로 검증 |
| AC-005 | 상대 기록 재생 일치 | 재생 경로 일치까지 검증 |
| AC-001 / AC-006 / AC-007 | 온보딩·원격 연산·오프라인 | 화면과 어댑터 구현 후 |

## 구조

```text
game/                     Godot 4.7 프로젝트
  src/domain/             규칙·생성기·검증기 (Godot 노드·SDK 무의존 순수 도메인)
    rng/pcg32.gd          결정론 PRNG. 사내 matgo 구현 재사용
    rules/gate.gd         게이트 4종과 성장 계산
    rules/duel_engine.gd  구간 해소 순서와 한 판 진행
    rules/strategies.gd   밸런스 검증용 고정 전략 6종
    course/               코스 데이터·생성기·검증기
  src/application/        대국 조정, 기록 직렬화, 리플레이 (예정)
  src/infrastructure/     저장, 시계 주입, 원격 문서 포트 (예정)
  src/presentation/       화면과 연출 (예정)
  tests/                  헤드리스 테스트
docs/game-design/         기획 문서 팩 (source of truth)
scripts/                  로컬·CI 공용 진입점
config/toolchain.lock     도구 버전 고정
```

`src/domain` 은 Godot 노드와 플랫폼 SDK 를 참조하지 않는다. 리플레이 재생과 대국 진행이
**같은 판정 코드**를 쓰기 때문이며, 두 경로가 갈라지면 재현이 깨진다.

## 규칙 요약

| 게이트 | 효과 | 겹쳤을 때 |
| --- | --- | --- |
| 불리기 | 내 군중 x1.3 ~ x1.8 | 뒤처진 쪽만 온전히 (동수면 절반씩) |
| 모으기 | 내 군중 + 그 구간 예상 규모의 55~135% | 뒤처진 쪽만 온전히 (동수면 절반씩) |
| 빼앗기 | 상대 군중의 15~25% 이동 | 뒤처진 쪽만 온전히 (동수면 상쇄) |
| 방패 | 빼앗기 무효화 + 상대의 10% 반격 | 양쪽 방패면 무효 |

세 성격이 순환 우위를 이룬다. 빼앗기는 성장하는 상대에게 강하고, 방패는 빼앗기에 강하며,
성장은 아무 일도 하지 않는 방패에 강하다. 여기에 **불리기와 모으기의 우열이 내 군중 수에 따라
뒤집히는** 2차 장치가 더해진다. 전환점은 `모으기 값 / (배수 - 1)` 이고, 모으기 값이 구간마다
그 시점의 예상 군중에 맞춰 커지므로 전환점이 판 내내 군중 궤적 근처에 머문다.

## 명령

```bash
# 도메인 헤드리스 테스트
scripts/test.sh

# 코스 생성기 대량 검증 (기본 10,000 시드)
scripts/validate_courses.sh --seeds 10000

# 전략 승률 행렬
scripts/strategy_matrix.sh

# 정적 검사 (컴파일 게이트와 같은 검사)
scripts/lint.sh
```

Godot 헤드리스는 스크립트 오류가 있어도 종료 코드 0 을 낼 수 있다. 위 진입점은 로그의
`SCRIPT ERROR` 와 `ERROR:` 를 함께 검사한다.
