# Google Play 데이터 안전 신고 근거

2026-10-21 실제 코드 기준. 최종 신고와 Console 저장은 아직 하지 않았다.

게임 전적과 재화, 설정, 튜토리얼과 진행 중인 판은 로컬에만 저장한다. Firebase, 서버 계정, 원격 기록, 별도 게임 분석 SDK 및 결제는 없다. 결과 이미지는 사용자가 공유창에서 선택한 대상에 전달한다.

Google Mobile Ads 25.5.0과 UMP 4.0.0이 포함된다. [Google의 해당 SDK 공개 항목](https://developers.google.com/admob/android/privacy/play-data-disclosure)은 IP 주소와 추정 대략적 위치, 앱 및 광고 상호작용, 성능과 진단 정보, 광고 ID와 앱 또는 기기 식별자의 수집 및 공유를 광고, 분석과 부정 이용 방지 목적으로 설명한다. 이 앱은 광고 ID 권한을 제거하지 않는다. 별도 위치 권한은 없다. SDK 데이터는 전송 중 TLS를 사용한다.

동의는 매 실행 갱신하며 canRequestAds 이전에 MobileAds를 초기화하거나 요청하지 않는다. 개인정보 선택이 필요한 지역은 설정의 UMP 진입점을 제공한다. 대상 연령은 13세 이상, 최대 광고 콘텐츠 등급은 T다. 연령 대상은 IARC 결과 등급을 미리 정하는 답안이 아니다.

신고는 광고 수집을 미수집으로 표시하지 않는다. Console의 실제 양식과 SDK의 최종 구성, 처리 목적, 필수 또는 선택 여부, 삭제 질문을 대조하고 CSV를 내보낸 뒤 검수한다. 실제 저장 전 완료 표시는 하지 않는다. AdMob의 EU 및 미국 주 개인정보 메시지, 공개 앱 연결과 app-ads.txt는 별도 확인한다.
