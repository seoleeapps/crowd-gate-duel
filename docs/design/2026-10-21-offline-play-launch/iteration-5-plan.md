# 다섯 번째 독립 기능 및 화면 검수 계획

승인 원문: 사용자는 추가 한 회차, 약10~15분, 개발 환경의7개 기능 검수 제안에 `추가 1회 승인`으로 답했다. 승인 응답을 받은 뒤 관찰한 시각은2026-10-21T00:36:35Z다. 이것은 기기 사용 승인이 아니다.
계획 기록 시각: 2026-10-21T00:43:05Z. 후보: 0e70326b0ef541dd52f84096c0d9c76adfb68eb0.
검수자: /root/ui_review, 구현자: /root. 페르소나: 반복 사용자와 저장 복구 회귀 검수자.

운영 광고 ID를 실제 Console에서 읽어 반영한 후보의 Godot CI39522362402와 Android CI39522362584가 모두 통과한 뒤에만 시작한다. 시작 및 종료 HEAD와 clean 상태를 확인하고 소스는 수정하지 않는다. 정수 판정과 Pcg32, 저장, 광고 조건은 기존 계약을 따른다.

한 회차에서 scripts/test.sh의275개 전체 단위 검사와 scripts/smoke.sh의 headless, en1080x1620, ko1080x2520, en1620x2160 실제 렌더링을 한 번씩 순서대로 실행한다. 각 여정은4시나리오279검사를 기대하며 tutorial, duel, progress, cosmetics, settings, ads, share 전부를 포함한다. 코스10000개는 같은 후보 CI의 통과 근거를 읽는다.

원본은 build/review-5 아래에 환경별로 저장한다. 진행과 공유는 user://e2e/review-5-*만 사용하고 사용자 저장에는 접근하지 않는다. 모든 명령에 GITHUB_SHA를 위 전체 SHA로 고정한다. Godot import를 겹치지 않는다. 종료 코드와 SCRIPT ERROR, ERROR:, Parse Error, ALL GREEN을 같이 검사하고 완성되지 않은 JSON을 통과로 세지 않는다.

무입력 미완료, 오답 후 해당 문제만 재시도, 튜토리얼과 일반 대국 저장 복원, 보상 미중복, 첫 특수 게이트의 시간 정지와 현재 수치, 광고 저장 우선과1회 시도, 실패 및 중복 콜백과45초 경계, 꾸미기 해금과 취소, 설정과 개인정보 선택, 재학습, 공유를 실행한다. 실제 앱 기본 포커스 및 시계와 개발 경계의 차이도 읽는다.

네 번째 태블릿 실패 R4-01의 군중 칩, 리본, 길, 캡처 양수 크기와 비어 있지 않은 결과 및 공유 장면, 재학습 완료를 직접 확인한다. safe_top_inset의 데스크톱0, Android와iOS 노치 변환 단위가 실제 _safe_top에서 사용되는지 확인한다. 영어와한국어의 quiz, 자막 및 숫자, 특수 아이콘, 홈, 꾸미기, 결과와 실제 공유 PNG도 직접 연다. 단순 경계 검사를 시각 검수로 바꾸지 않는다.

1~4회차의 원본 실패는 그대로 보존하고 이번 결과에서 해결 근거를 연결한다. 판정은 기능과UX 각각 남긴다. 보고서는 release-artifacts/qa/iteration-5-result.md에 작성한다. 승인된 한 회차 뒤 미충족이면 원본을 보존하고 중단하며 임의 재실행이나6회차를 시작하지 않는다. Android/iOS 기기, 실제 UMP와 광고 및 네이티브 공유창, 청취와 햅틱, 실제 사용자 이해도와 이탈률은 이번 검수 범위가 아니며 통과로 주장하지 않는다.
