# 네 번째 독립 검수 제안, 승인 전

3회차의 실패와 원본은 release-artifacts/qa/iteration-3-result.md에 보존했다. 세 번째 최종 후보 3fef4d6은 단위 264개와 headless, 영어 짧은 화면, 영어 태블릿을 통과했지만 한국어 긴 화면에서 광고 시도 0에 따른 세 항목이 실패했다. 실제 창 포커스를 대체하지 못한 경계를 단위 검사로 재현하고 수정했다. 작성자의 수정 후 한국어 긴 화면 실행은 통과했으며 독립 검수로 계산하지 않는다.

요청 범위는 같은 검수자 /root/ui_review가 수정 후 고정한 후보 SHA에서 전체 7개 기능을 한 번 검수하는 것이다. 단위 검사, headless, 영어 1080x1620, 한국어 1080x2520, 영어 1620x2160을 순차 실행하고 장면 PNG와 공유 PNG를 직접 본다. 포커스 상실의 실제 앱 동작 보존, 고정 검수 시계, 첫 광고와 저장 우선, 이전 회차에서 수정한 아이콘과 배치, 구버전 저장 전환을 재확인한다.

예상 추가 시간은 10~15분이며 별도 이미지 및 음악 생성 API를 호출하지 않는다. 기기와 사용자 저장은 사용하지 않는다. 실행 데이터는 user://e2e/review-4-*에, 원본은 build/review-4에, 실행 전 계획과 결과는 release-artifacts/qa에 보존한다. 승인 전에 실행하지 않는다. 이 한 회차 뒤 미충족 항목이 남으면 다섯 번째 회차를 시작하지 않고 보고한다.

승인 대상은 추가 개발 환경 검수 한 회차다. Google 로그인, 기기 사용과 실제 광고 송출 검증은 각각 별도 상태다. 승인 시각과 근거를 확인한 다음 실제 회차 계획을 작성하고 실행한다.
