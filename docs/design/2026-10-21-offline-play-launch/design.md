# Crowd Gate Duel 완성과 Google Play 공개 출시

실행 티켓: https://github.com/seoleeapps/crowd-gate-duel/issues/7

승인 근거는 2026-10-21 대화의 구현 지시와 전달된 전체 출시 계획이다. 제품명 Crowd Gate Duel, 한국어명 갈림길 군중 대전, 오프라인 봇 전용, 전면광고, 13세 이상, 영어와 한국어, 지원 가능한 국가 전체, Google Play 공개 100%까지가 승인 범위다. Seolee Apps 계정을 명시한 사용자 결정을 적용한다. 기기 접근은 승인되지 않았다.

## 흐름과 책임

첫 실행과 구버전 이용자는 필수 체험 4단계와 이해 확인 2문제를 직접 선택한다. 시간제한과 자동 완료는 없다. 오답은 실제 숫자 변화를 보여 준 뒤 그 문제만 재시도한다. 성공한 단계만 로컬 저장에 기록하며 기존 전적, 재화와 이미 지급한 완료 보상은 보존한다. 이후 홈, 봇 대국, 결과, 꾸미기, 설정으로 이어진다. 설정에서 재학습할 수 있다.

기존 한낮 장터 화면, 아이콘, 선택 표식과 숫자 변화를 재사용한다. 설명은 상황별 한 문장이다. 빼앗기와 방패는 일반 대국 최초 등장 때 시계를 멈추고 실제 판정 예시를 보여 준다.

순수 도메인의 정수 판정과 Pcg32는 유지한다. Onboarding은 성공 단계와 정답, DuelSession은 판 진행, ProgressStore는 보상과 복구, 화면은 입력과 연출을 맡는다. 원격 조회, 업로드 큐, 연결 상태, 보상형 재도전은 승인된 오프라인 및 전면광고 모델로 대체하므로 제거한다. 선택 기록의 로컬 재생 계약은 보존한다.

Android 경계는 AdMob, UMP와 공유창이다. 개발 검수는 이 경계만 대체한다. 광고는 동의 후 미리 준비하며 판 결과와 보상을 먼저 저장한다. 결과를 보여 준 다음 준비된 광고만 1회 시도하며 늦은 로드는 다음 판에 사용한다. 닫힘부터 45초 간격, 세션 및 일 상한 없음이다. 튜토리얼, 판 진행, 앱 시작 및 복귀에는 표시하지 않는다. 실패와 중복 콜백은 결과 화면을 막거나 재지급하지 않는다.

## 인수조건과 검수

- AC-L01 무입력 미완료, 오답 재시도, 두 이해 확인 문제, 재시작 이어하기, 구버전 보상 중복 방지.
- AC-L02 봇 배지, 난이도, 보상, 꾸미기, 설정, 저장 복원, 첫 특수 게이트 예시.
- AC-L03 동의 전 광고 요청 없음, 판당 1회, 결과 저장 우선, 준비되지 않으면 즉시 진행, 실패 및 중복 콜백, 44,999ms와 45,000ms 경계.
- AC-L04 실제 좌표 입력으로 시작, 대국, 결과, 저장과 재실행을 검수. 영어와 한국어, 짧은 화면, 긴 화면, 태블릿 너비에서 렌더링.
- AC-L05 공개 PR에는 비밀값 없이 GitHub Ubuntu에서 컴파일, 전체 테스트, 코스 10,000개 검증, 화면 입력 검수를 실행하고 로그와 캡처를 보관.
- AC-L06 신뢰된 출시 태그에서 서명 AAB, API 36 이상, 패키지와 인증서, 16KB 정렬 확인. 내부 배포 뒤 별도 기기 승인으로 UMP, 광고 표시와 닫기, Android 공유창만 검수. 심사, 승인, 공개와 스토어 readback을 각각 기록.

L3와 독립 기능 및 화면 검수 3회를 적용한다. 회차별 계획은 실행 전에 기록한다. 초보자 5명 테스트는 필수 출시 조건에서 제외되었고 자동 검수로 사람의 이해도나 이탈률을 입증하지 않는다. 네이티브 SDK는 개발 환경의 대체 구현 통과로 실제 동작을 주장하지 않는다. TDD는 순수 로직과 저장, 광고 상태에 적용하고 아트 및 플랫폼 SDK는 실제 렌더링, 빌드, 승인된 최소 기기 실행으로 검증한다.

## 출시와 복구

패키지 후보 com.seoleeapps.crowdgateduel, 1.0.0 (1). 등록 전 소유 계정, 이름과 패키지를 실제 Console에서 확인한다. 서명과 광고 ID를 추측하거나 타 앱 값을 복사하지 않는다. 필수 검증이나 자격증명, 계정, 기기 승인에 막히면 해당 상태를 보존하고 독립적으로 가능한 작업을 계속한다. 공개 후 결함은 배포 중단과 새 수정 버전으로 대응하며 태그와 서명을 교체하지 않는다.
