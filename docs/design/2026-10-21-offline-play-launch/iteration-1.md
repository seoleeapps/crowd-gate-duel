# 독립 기능 및 화면 검수 1회 계획

계획: 2026-10-21, 실행 전 작성. 대상은 이 작업 브랜치의 첫 실행 가능한 오프라인 후보이며 실행자가 실제 SHA를 기록한다. 구현자는 root, 검수자는 별도 에이전트다.

범위는 tutorial, duel, progress, cosmetics, settings, ads, share의 개발 환경 전체다. 새 사용자 관점에서 입력, 선택 결과, 오답, 저장 이어하기, 보상, 봇 표시, 탐색과 화면 가독성을 검수한다. 네이티브 UMP와 광고, 공유창은 미실행으로 구분한다.

scripts/test.sh, scripts/smoke.sh, 렌더링 여정을 실행한다. ko 1080x2340, en 1080x1620 화면에서 전체 흐름을 검수한다. 실행별 user://e2e/review-1-* 저장만 사용한다. 실제 좌표 입력을 유지한다. 캡처를 직접 열고 원본 한낮 장터 아트와 비교한다. 결과는 발견 위치, 재현, 사용자 영향, 수정 제안, 기능과 UX 판정으로 기록하며 코드 수정은 하지 않는다.
