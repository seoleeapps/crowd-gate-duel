# 독립 기능 및 화면 검수 2회 계획

2026-10-21 실행 전 계획. 검수자는 /root/ui_review이며 구현자 root와 다르다. 실행 직전 커밋을 기록한다. 1회차의 원래 실패와 영어 미완료는 보존한다.

전체 기능 tutorial, duel, progress, cosmetics, settings, ads, share를 재실행한다. 1회차 중복 표식과 결과 및 공유 카드의 잘림, 오래된 설정 문구를 재확인한다. OS 포커스는 테스트 경계에서 고정하되 제품의 기본 일시정지는 유지한다.

영어 1080x1620, 한국어 1080x2520, 태블릿 1620x2160의 실제 좌표 입력 및 렌더링을 확인한다. 저장 경로는 user://e2e/review-2-*이며 로그와 PNG는 build/review-2/ 아래 둔다. 작은 화면의 버튼, 자막과 타이머, 꾸미기 목록 드래그와 설정 탐색을 검수한다. 고난도 초기 진행은 격리 fixture로 주입하고 실제 코스와 입력으로 첫 빼앗기, 방패 안내 중 시간 정지, 확인 후 재개를 검수한다. 손상된 테스트 저장의 사본 복구도 확인한다.

코드와 사용자 데이터, 다른 작업 프로세스 및 기기는 조작하지 않는다. 네이티브 SDK 동작은 아직 검수하지 않는다. 발견한 기능 및 UX 문제를 근거와 함께 보고하고 회차 내 반복 실행은 문제 재현에 필요한 한정된 범위만 수행한다.
