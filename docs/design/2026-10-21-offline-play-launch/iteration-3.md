# 독립 기능 및 화면 검수 3회 계획

2026-10-21 실행 전 작성. 구현자는 root, 검수자는 /root/ui_review다. 실행 시작 시 실제 후보 SHA를 기록한다. 1회차와 2회차의 원래 실패는 보존하고 해결 근거를 연결한다.

전체 기능 tutorial, duel, progress, cosmetics, settings, ads, share를 최종 코드로 재실행한다. headless, 영어 1080x1620, 한국어 1080x2520, 영어 태블릿 1620x2160을 순차 실행하고 원본 PNG와 공유 파일을 직접 본다. 이번 회차의 지정 경로는 user://e2e/review-3-*와 build/review-3/다. 결과 보고서는 source SHA를 바꾸지 않도록 release-artifacts/qa/iteration-3-result.md에 보존하며 PR의 실행 결과에서 연결한다.

기능과 UX 기대 결과: 무입력은 대기, 오답 문제만 재시도, 성공 단계 저장과 재시작, 완료 보상 중복 없음, 모든 일반 상대 봇 표시, 실제 좌표 입력, 결과 저장 후 광고 1회 시도, 실패 및 중복 콜백 이후 결과 사용, 첫 특수 게이트의 현재 수치와 실제 정수 예시 및 시간 정지, 꾸미기 목록 드래그와 해금 취소 및 구매, 설정과 재학습, 손상 사본 복구, 실제 카드 렌더링과 개발 공유 저장이다.

2회차 수정은 자막의 폭과 숫자 가림, 세계 속 숫자의 잘림과 겹침, 짧은 홈 버튼 간격, 반응형 꾸미기 열 수, 어두운 카드의 아이콘 대비, 현재 게이트 수치를 쓰는 예시다. 좌표 검사에도 자막과 군중 숫자의 경계와 겹침, 홈 버튼 겹침과 꾸미기 가로폭, 터치 대상 48dp를 추가했다. 버튼을 누르는 도우미는 viewport 밖 좌표를 성공으로 반환하지 않는다. 해금 확인창도 실제 좌표로 검수한다.

모든 PNG를 같은 이름으로 덮어쓰지 않고 시나리오별 prefix로 보존한다. 작성자와 다른 검수자가 기능과 화면을 실제 재현한다. 실제 사용자 이해도와 유지율, 네이티브 UMP와 광고 송출 및 Android 공유창은 이번 개발 검수에서 증명하지 않는다. 사용자 저장, 기기와 다른 작업 프로세스는 조작하지 않는다. 3회 뒤 미해결이면 추가 회차를 시작하지 않고 남은 문제와 필요한 승인 범위를 보고한다.
