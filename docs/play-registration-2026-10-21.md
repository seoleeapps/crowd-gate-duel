## 계정과 앱

Google Play의 실제 로그인은 지정된 legacy 계정과 일치했다. 개발자는 Seolee Apps, 개인 계정, ID5547060480954653351이다. 새 앱 기본 계정과 다른 이번 선택은 사용자가 승인한 출시 계획의 Seolee Apps 지정을 따랐다. 계정과 권한, 다른 앱은 변경하지 않았다.

생성 전 실제 앱 목록9개에 Crowd Gate Duel은 없었고 생성 화면에서 com.seoleeapps.crowdgateduel의 사용 가능 표시를 확인했다. Crowd Gate Duel, 영어 미국 기본 언어, 무료 게임으로 생성했다. 생성 후 목록의 제품명과 패키지, 앱 대시보드를 다시 읽었다. Play 앱 ID는4972940845333469610이며 현재 임시 앱이다. 최초 생성 요청 뒤 화면 전환이 지연되어 앱 목록을 따로 읽었고 생성 요청을 다시 보내지 않았다.

## Play 신고와 콘텐츠 등급

IARC는 판타지 인물의 멀리서 짧게 묘사되는 비현실적인 충돌과 유혈 없음을 신고했다. 실제 결과는 한국 전체이용가, 북미10세 이상, PEGI7, 대만12세 이상 등이다. 2026-10-21 오전9:53 제출 뒤 Console의 IARC 상태는 완료됨이다. 인증 ID는 이후 재조회에도 `-`이므로 발급된 ID를 확인했다고 기록하지 않는다. 데이터 안전은 GMA25.5.0의 대략적인 위치, 앱 상호작용, 진단과 기기 식별자를 수집 및 공유로 신고했다. 광고, 분석과 부정행위 예방 목적, 임시 처리가 아님, 전송 암호화, 계정 없음과 개발자 측 삭제 요청 미제공을 저장했다. 광고 ID 자체는 OS에서 삭제할 수 있지만 앱 집합 ID와 제한 광고의 IP 처리를 모두 중지하는 앱 선택은 없으므로 해당 유형 전체는 필수로 신고했다. 저장 응답과 미리보기를 읽었다. 게임 전적과 재화는 서버에 전송하지 않는다. 근거는 [GMA 공식 데이터 공개](https://developers.google.com/admob/android/privacy/play-data-disclosure?hl=en)다.
