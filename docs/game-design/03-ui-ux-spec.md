## 내비게이션 그래프

```text
첫 실행 → SCR-004 온보딩 대국 → SCR-003 결과 → SCR-001 홈
SCR-001 홈 → SCR-002 대국 → SCR-003 결과 → SCR-001 홈
SCR-001 홈 → SCR-005 프로필과 꾸미기 → SCR-001 홈
SCR-001 홈 → SCR-006 설정 → SCR-001 홈
SCR-003 결과 → SCR-002 대국 (재대국 또는 보상 광고 재도전)
```

진입점은 홈 하나다. 대국 중에는 일시정지 외의 이탈 경로가 없다.

## 디자인 시스템

- 세로 고정 9:16 기준, 안전 영역 상하 여백을 별도 레이어로 둔다
- 색은 두 진영색(내 편 따뜻한 주황, 상대 편 차가운 청록)과 중립 회색만 쓴다. 게이트 종류는
  색이 아니라 **아이콘 모양**으로 구분한다. 색각 이상에서도 구분되어야 하기 때문이다
- 타이포는 숫자 전용 굵은 산세리프 1종과 본문 1종. 판 중에 읽어야 하는 숫자는 군중 수와 게이트 수치뿐이다
- 모든 상호작용 요소는 48dp x 48dp 이상(SRC-008). 게이트 칸은 화면 가로의 3분의 1 폭에 높이 96dp 이상으로 둔다
- 판 진행 중 화면에 배너·버튼·패널을 추가하지 않는다. 일시정지 버튼 하나만 예외다

## 화면 계약

### SCR-001 홈

- 목적: 바로 한 판 시작하게 한다
- 진입: 앱 실행, 결과 화면에서 복귀 / 이탈: 대국, 프로필, 설정
- 시선 우선순위: 중앙의 큰 시작 버튼 → 내 군중 미리보기 → 대역 표시 → 하단 보조 진입점
- 레이아웃: 상단 대역과 깃털, 중앙 상단 내 군중 대기 장면, 중앙 하단 시작 버튼, 하단 프로필·설정
- 주 행동: 시작 / 보조 행동: 꾸미기, 설정
- 카피: 시작 버튼은 동사 한 단어. 대역은 숫자와 이름
- 분석 이벤트: `home_view`, `duel_start_tap`
- 모션: 대기 중 군중이 제자리에서 흔들린다. 시작 버튼은 정지 상태다

### SCR-002 대국 화면 (메인 플레이 화면)

- 목적: 게이트 선택과 그 결과를 한 화면에서 보여준다
- 진입: 홈 시작, 결과 재대국 / 이탈: 결과 화면, 일시정지
- 시선 우선순위: **누가 앞서는가 → 내려오는 게이트 띠 → 확약 타이머 → 군중 수 숫자**
- **순위 가독성이 이 화면의 첫 번째 요구다.** 겹치면 뒤처진 쪽이 온전히 가져가므로, 앞서 있으면
  상대가 고를 칸을 피해야 하고 뒤처져 있으면 노려야 한다. 매 구간 정답이 순위에 따라 뒤집히는데
  확약 시간이 3초뿐이므로, 화면은 **수치를 비교하기 전에** 순위를 알려줘야 한다.
  구체적인 표현 방법은 `ui/duel-screen-layout-options.html` 의 배치안 선택으로 정한다
- 레이아웃 구역 (A-0 B안 "하나의 언덕길", 시안 `ui/duel-style-a.png`)
  - 상단 9%: 진행 리본(구간 위치)과 일시정지 버튼 하나. 언덕길 위에 겹쳐 놓는다
  - 중앙 63%: 정상으로 오르는 **하나의 언덕길**에 내 무리와 상대 무리. 앞선 쪽이 더 높이 선다.
    높이는 두 군중 수의 로그 비로 정한다. 무리 발끝 높이마다 진영색 가로 점선을 긋는다.
    **화면의 주인공은 여기다**
  - 중앙 하단 21%: 게이트 띠 3칸. 각 칸에 아이콘과 수치
  - 하단 7%: 확약 타이머 바
  - 긴 화면에서는 언덕길만 늘고, 짧은 화면(세로/가로 2 미만)에서는 언덕길을 리본 아래에서 시작한다
- 주 행동: 게이트 칸 탭 / 보조 행동: 일시정지
- 숫자 표시 규칙: 군중 수는 각 무리 바로 위에 붙여 표시한다. **별도 수치 패널이나 카드 목록을
  만들지 않는다.** 화면을 지배하는 것은 불어나는 무리와 내려오는 게이트 띠다
- 동수 표시: 시작은 항상 동수이고, 동수에서는 겹쳐도 반씩 나눌 뿐이라 노릴 이유가 없다.
  **동수는 우열이 없는 상태로 따로 보이게 한다.** 어느 한쪽이 앞선 것처럼 읽히면 안 된다
- 카피: 게이트 칸은 아이콘과 수치만. 설명 문장을 쓰지 않는다
- 분석 이벤트: `segment_present`, `gate_commit`, `gate_reveal`, `gate_split`, `gate_yield`, `duel_finish`
- 에셋: 군중 실루엣 인스턴싱, 게이트 띠 프레임, 종류 아이콘 4종, 양보 표식, 반감 표식(동수 전용)
- 모션: 게이트 띠는 위에서 아래로 내려온다. 확약 후 내 칸에 자물쇠가 닫힌다. 공개 시 양쪽 칸이 동시에 뒤집힌다
- 접근성: 게이트 칸마다 목적과 결과를 설명하는 고유 콘텐츠 설명(SRC-008). 예로 "불리기, 두 배"

### SCR-003 결과 화면

- 목적: 승패를 한 장면으로 남기고 공유 가능한 카드를 만든다
- 진입: 대국 종료 / 이탈: 홈, 재대국, 보상 광고 재도전
- 시선 우선순위: 충돌 직후 정지 화면 → 승패 문구 → 최종 군중 수 대비 → 행동 버튼
- 레이아웃: 상단 결과 장면 캡처, 중앙 양쪽 최종 수와 결정적 구간 표시, 하단 버튼 3개
- 주 행동: 한 판 더 / 보조 행동: 공유, 홈
- 결정적 구간 표시: 격차가 가장 크게 벌어진 구간 한 곳을 되짚어 보여준다. 다음 판의 학습이 된다
- 카피: 승패는 단어 하나. 공유 카드에는 앱 이름과 최종 수만 들어간다
- 분석 이벤트: `result_view`, `result_share_tap`, `rewarded_retry_optin`, `rematch_tap`
- 광고 경계: 광고 진입점은 이 화면에만 존재한다. 옵트인 수락 버튼과 보상 사전 고지를 함께 표시한다(SRC-009)

### SCR-004 온보딩 대국

- 목적: 설명 없이 규칙을 겪게 한다
- 진입: 첫 실행 / 이탈: 결과 화면
- SCR-002 와 같은 레이아웃을 쓰되 게이트가 1구간에서 2칸만 나오고 손 표시가 한 칸을 가리킨다
- 1·2구간은 손이 가리키는 칸만 누를 수 있다. 나머지 칸은 흐리게 보인다
- 2구간에서 상대가 반드시 같은 칸을 고른다. 이때 플레이어가 뒤처진 상태가 되도록 1구간을 구성해,
  겹쳐서 내가 온전히 가져가는 사건을 먼저 겪게 한다
- 상대는 연습 상대이며 수치 표식과 게이트 표식에 "연습" 배지를 붙인다(DEC-016)
- 건너뛸 수 없고 20초 이내에 끝난다
- 분석 이벤트: `onboarding_segment_complete`, `onboarding_split_seen`, `onboarding_finish`

### SCR-005 프로필과 꾸미기

- 목적: 내 전적과 코스메틱을 본다
- 진입: 홈 / 이탈: 홈
- 시선 우선순위: 내 무리 미리보기 → 깃발·팔레트 목록 → 전적
- 주 행동: 코스메틱 적용 / 보조 행동: 깃털로 해금
- 판매 항목이 승패에 영향을 주지 않음을 목록 상단에 한 줄로 표시한다
- 분석 이벤트: `cosmetic_view`, `cosmetic_equip`, `cosmetic_unlock`

### SCR-006 설정

- 목적: 접근성과 데이터 관리
- 진입: 홈 / 이탈: 홈
- 항목: 확약 시간 연장, 진동, 소리, 음악, 색각 보조 표시 강화, 언어, 진행 초기화, 개인정보 고지
- 확약 시간 연장은 접근성 항목이며 켜면 대역 매칭에 반영된다(DEC-008)
- 분석 이벤트: `settings_view`, `commit_time_extend_toggle`

## 피드백과 게임 필

핵심 행동마다 복수 채널로 피드백을 준다. 숫자만 바뀌는 피드백은 쓰지 않는다.

| 행동 | 시각 | 소리 | 햅틱 |
| --- | --- | --- | --- |
| 게이트 확약 | 선택 칸이 눌리고 자물쇠가 닫힌다 | 짧은 잠금음 | 가벼운 탭 |
| 동시 공개 | 양쪽 칸이 동시에 뒤집힌다 | 뒤집힘음 | 없음 |
| 양보 발생(내가 뒤처짐) | 두 칸이 연결되고 상대 무리가 멈칫하며 내 쪽만 불어난다 | 짧은 통과음 | 중간 세기 1회 |
| 양보 발생(내가 앞섬) | 두 칸이 연결되고 내 무리가 제자리에서 막힌다 | 낮은 둔탁음 | 강한 1회 |
| 반감 발생(동수) | 두 칸이 연결되고 양쪽에 절반 표식이 뜬다 | 중간 음 | 약한 1회 |
| 군중 증가 | 무리가 실제로 불어나며 개체가 튀어나온다 | 상승 음계 | 증가량 비례 짧은 연속 |
| 빼앗김 | 내 개체가 상대 레인으로 끌려간다 | 흡입음 | 중간 세기 |
| 방패 반격 | 빼앗기 화살이 튕겨 되돌아간다 | 금속 타격음 | 강한 1회 |
| 결승 충돌 | 두 무리가 부딪히고 화면이 정지한다 | 충돌음 후 정적 | 강한 1회 |

증가량이 클수록 개체가 더 많이, 더 빠르게 튀어나온다. 수치의 크기를 숫자가 아니라 장면의
밀도로 전달한다.

## 접근성

- 터치 대상 48dp x 48dp 이상, 게이트 칸은 그보다 크게(SRC-008)
- 명암비: 작은 텍스트와 굵은 소형 텍스트 4.5:1 이상, 그 외 3:1 이상(SRC-008)
- 게이트 종류를 색이 아니라 아이콘 모양으로 구분한다. 색각 보조 표시 강화 옵션에서 아이콘에 패턴을 추가한다
- 확약 시간 연장 옵션을 제공한다. 기본 대역 시간의 1.5배까지 늘릴 수 있다(DEC-008)
- 모든 상호작용 요소에 목적과 결과를 설명하는 고유 콘텐츠 설명을 붙이고 장식 요소는 설명을 제거한다
- 햅틱과 소리는 각각 끌 수 있으며, 하나를 꺼도 시각 피드백만으로 모든 사건이 구분된다
- 화면 흔들림 강도를 줄이는 옵션을 둔다

## 첫 세션 스토리보드

1. 앱 실행. 로고 없이 바로 SCR-004 로 들어간다. 첫 화면에 약관 전면 차단을 두지 않고
   하단 고지 링크로 처리한다. 사내 기록에서 첫 실행 동의 게이트가 진입 마찰로 관찰됐기 때문이다(SRC-003)
2. 1구간. 게이트 2칸과 손 표시. 누르면 무리가 불어난다
3. 2구간. 상대가 같은 칸을 고른다. 뒤처져 있던 내가 그 칸을 온전히 가져가고 상대는 멈칫한다.
   **여기가 온보딩의 핵심 순간이다.** "같은 길을 고르면 뒤처진 쪽이 먼저 지나간다"를 문장이
   아니라 사건으로 배운다
4. 3구간. 3칸 정상 제시. 스스로 고른다
5. 결승 충돌과 결과 카드. 여기까지 20초
6. 홈 진입. 시작 버튼 탭
7. 첫 일반 대국 5구간, 약 40초. 상대는 실제 기록 또는 배지가 붙은 봇
8. 결과 화면에서 결정적 구간 되짚기를 본다
9. 한 판 더. 여기까지 약 4분이 첫 세션이다
