## 아트 방향

키워드는 **축제 행렬**이다. 서로 다른 깃발을 든 종이 인형 무리가 언덕길을 올라 정상에서
부딪힌다. 전투가 아니라 행렬이고, 지는 쪽도 넘어질 뿐 다치지 않는다. 만 13세 이상 전 연령을
상정하므로 폭력 묘사와 유혈이 없다.

플랫 카툰에 얇은 외곽선을 쓴다. 명도 대비를 강하게 잡아 작은 화면에서 무리의 크기 차이가 한눈에
읽히게 한다. 질감과 그라디언트는 배경 레이어에만 쓰고 캐릭터와 UI 는 단색으로 둔다.

## 시각 문법

- **화면의 주인공은 두 무리다.** 불어나는 양과 줄어드는 양이 숫자보다 먼저 읽혀야 한다
- 진영은 색으로만 구분한다. 내 편은 따뜻한 주황, 상대는 차가운 청록, 중립 요소는 회색이다
- 게이트 종류는 **색이 아니라 아이콘 모양**으로 구분한다. 색각 이상 대응이자 색을 진영 표시에만
  쓰기 위한 규칙이다. 불리기는 벌어지는 화살표 두 개, 모으기는 모이는 점들, 빼앗기는 갈고리,
  방패는 둥근 방패다
- 군중 개체는 개별 캐릭터가 아니라 **실루엣 한 종의 반복**이다. 팔레트와 깃발만 교체한다.
  개체를 늘려도 제작비가 늘지 않아야 하기 때문이다
- 수가 많아지면 개체 크기를 줄이고 밀도를 높인다. 200명을 넘으면 뒤쪽을 실루엣 덩어리로 합쳐
  연산과 시각 복잡도를 동시에 억제한다
- 배경은 언덕길 3레이어 패럴랙스이며 구간이 진행될수록 정상이 가까워진다

## 캐릭터와 세계

세계관은 **깃발 축제**다. 마을마다 깃발이 다르고 해마다 정상에 먼저 무리를 모아 올라가는 마을이
그해의 축제를 연다는 설정이다. 적대나 정복의 서사가 없다.

- 군중 개체: 종이 인형 실루엣 1종. 걷기 2프레임. 팔레트 스왑과 깃발 교체로 파생
- 깃발: 기본 8종. 무늬는 기하 도형 조합으로 만들어 생성 파이프라인에서 확장 가능
- 상대 표시: 표시명과 대역만. 아바타 초상을 만들지 않는다. 제작비를 늘리지 않기 위한 결정이다
- 봇 상대: 무채색 깃발과 배지로 구분한다. 사람 표시명을 쓰지 않는다(DEC-003)

## UI 아트 경계

- UI 는 단색과 얇은 외곽선만 쓴다. 장식 프레임과 금속 질감을 쓰지 않는다
- 게이트 띠는 화면을 가로지르는 띠 하나이며 칸 사이 구분선만 둔다
- 판 진행 중 화면에 UI 요소를 추가하지 않는다. 존재하는 것은 진행 리본, 게이트 띠,
  확약 타이머, 일시정지 버튼뿐이다
- 결과 카드는 공유를 전제로 설계한다. 정사각형과 세로 두 규격을 만들고 앱 이름과 최종 수만 넣는다

## VFX 언어

물리 엔진을 쓰지 않으므로 VFX 는 전부 CPUParticles2D 와 트윈으로 만든다.

- **증가**: 무리 위로 개체가 튀어나오며 잔상 입자가 위로 흩어진다. 증가량에 비례해 입자 수가 늘어난다
- **감소**: 개체가 흐려지며 아래로 가라앉는다
- **빼앗김**: 내 개체가 궤적을 그리며 상대 레인으로 끌려간다. 궤적이 방향을 명확히 보여준다
- **방패 반격**: 갈고리가 방패에 맞고 튕겨 되돌아간다. 되돌아간 궤적이 상대 레인에서 감소로 이어진다
- **반감**: 두 선택 칸 사이에 연결선이 생기고 각 칸에 절반 아이콘이 겹쳐진다
- **결승 충돌**: 두 무리가 만나는 순간 화면이 0.3초 정지하고 승리 측 색으로 화면이 한 번 물든다

화면 흔들림은 결승 충돌에만 쓰고 설정에서 강도를 줄일 수 있다.

BGM 은 홈과 대국 각 1곡이며 대국 곡은 구간이 진행될수록 레이어가 하나씩 얹히는 구조로 만들어
긴장이 자연히 오르게 한다. 루프는 이음매가 들리지 않도록 후처리한다.

현재 구현(2026-09-29): 음악 생성 도구가 층별 음원(stem)을 만들지 못해, 대국 곡 한 곡에 저역 통과
필터를 걸고 구간이 쌓일수록 필터를 열어 판 초반엔 먹먹하고 후반엔 밝게 들리게 했다. 효과음 12종은
절차 합성이다. 만든 방법과 권리 근거는 `game/assets/README.md` 에 있다. 사람이 직접 듣는 확인(A-5)은 2026-09-30 사용자가 BGM 2곡·승패 악구·효과음 12종을 듣고 통과시켰다.

소리와 햅틱은 각각 끌 수 있고, 둘 다 꺼도 시각 피드백만으로 모든 사건이 구분되어야 한다.

## 생성과 라이선스

- 이미지 자산은 사내 생성 파이프라인으로 만들고 결과물을 저장소에 보관한다
- BGM 과 SFX 는 생성 도구로 만들고 루프 후처리를 거친다
- 라이선스 IP, 실존 인물, 실존 지명, 상표를 쓰지 않는다
- 경쟁작의 아이콘, UI 배치, 캐릭터, 오디오를 참조 자료로 두지 않는다. 사내 역분석 기록에서
  가져오는 것은 구조적 교훈 문장뿐이며 시청각 자산은 가져오지 않는다
- 생성 자산의 제작 방식과 도구, 권리 근거를 저장소에 함께 기록한다
