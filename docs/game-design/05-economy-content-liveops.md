## 재화 Source와 Sink

재화는 **깃털** 하나뿐이다. 재화를 하나로 둔 이유는 환전 구조가 생기면 승패에 영향을 주는
상품이 끼어들 여지가 생기기 때문이다.

| 구분 | 항목 | 수량 | 빈도 상한 |
| --- | --- | --- | --- |
| Source | 승리 | 10 | 없음 |
| Source | 패배 | 3 | 없음 |
| Source | 무승부 | 5 | 없음 |
| Source | 일일 첫 승 | 20 | 1일 1회 |
| Source | 3판 대결 승리 | 25 | 없음 |
| Source | 주간 리그 정산 | 30~150 | 주 1회 |
| Sink | 깃발 무늬 해금 | 150 | 항목당 1회 |
| Sink | 군중 팔레트 해금 | 120 | 항목당 1회 |
| Sink | 결과 카드 테두리 해금 | 200 | 항목당 1회 |

깃털로 살 수 있는 것은 외형뿐이다. 확약 시간, 게이트 확률, 시작 군중 수, 대역 매칭에 영향을 주는
상품이 존재하지 않는다.

## 밸런스 모델

밸런스의 목표는 **어떤 고정 전략도 통하지 않는 상태**를 유지하는 것이다. 수치 자체보다 수치가
만드는 판단 구조가 대상이다.

핵심 수치 범위는 다음과 같다.

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 시작 군중 | 12 | 모으기 최소값(+10)과 비슷해 1구간부터 불리기·모으기 우열이 갈린다 |
| 불리기 배수 | 구간 목표 이득에서 역산 (x1.2~x2.6 범위로 제한) | 복리라 고정 범위로 두면 후반에 모으기를 압도한다(DEC-013) |
| 모으기 값 | 구간 목표 이득의 80~125% | 목표 이득은 그 구간 예상 군중의 40~90% 다. 전환점이 늘 군중 근처에 놓인다 |
| 빼앗기 비율 | 15~25% | 25% 를 넘으면 뒤처진 쪽 역전이 지나치게 쉬워진다 |
| 방패 반격 | 상대의 10% | 빼앗기 기대값보다 낮아야 방패가 항상 정답이 되지 않는다 |
| 겹침 우선권 | 뒤처진 쪽이 독점 | 대칭 반감은 격차를 안 바꿔 지배 전략을 만든다(DEC-012) |
| 무승부 상한 | 5% 미만 | 생성 검증 조건 |

세 성격의 순환 우위(성장 > 방패 > 빼앗기 > 성장)가 1차 장치이고, 불리기·모으기의 전환점 이동이
2차 장치다. 두 장치가 함께 있어야 고정 전략 승률이 60% 아래로 유지된다.

수치로 이기는 구조가 생기지 않는다.

## 콘텐츠 재고

공급 모델은 `procedural` 이다. 콘텐츠의 본체는 **코스 생성기**와 **상대의 선택 분포**다.

생성 공간 크기는 다음과 같다. 게이트 4종(확장 시 6종) 중 구간당 3칸 조합, 각 칸의 수치 대역,
구간 수 5~9 를 곱하면 코스 기준 조합 공간이 10^9 을 넘는다. 여기에 상대의 선택 시퀀스가
곱해지므로 실제 대국 공간은 그보다 훨씬 크다.

한계 비용은 0 이다. 코스 1건을 더 만드는 데 드는 사람 비용이 없다.

소진 지평은 3,650일로 잡는다. 근거는 두 가지다. 첫째, 코스가 시드에서 무한히 나온다.
둘째, 같은 코스라도 상대가 다르면 다른 문제가 되므로 생성기의 반복감이 곧바로 게임의
반복감이 되지 않는다. 이 구조는 사내 포트폴리오의 추상 보드 게임들이 콘텐츠 추가 없이
수명을 유지하는 방식과 같고, 상대 풀이 스스로 갱신되는 축이 하나 더 붙은 형태다.

새 원화 제작이 아니며, 필요할 때만 진행하는 선택 작업으로 둔다.

## 수익화 카탈로그

프로토타입에서는 전부 목 경계이며 실제 구성은 DEC-001 로 사람이 정한다.

| 항목 | 유형 | 성격 | 정책 근거 |
| --- | --- | --- | --- |
| 광고 제거 | 1회성 인앱결제 | 결과 화면 광고 제거 | |
| 깃발·팔레트·테두리 묶음 | 1회성 인앱결제 | 외형만 | |
| 패배 후 재도전 | 보상형 광고 | 같은 코스 1회 재도전 | SRC-009 |

보상형 광고는 공식 정책을 그대로 따른다. 명시적 수락 버튼을 통한 옵트인, 시청 전 요구 행동과
보상의 명확한 고지, 건너뛰기와 닫기 가능. 현금·암호화폐·기프트카드 같은 직접 금전 보상을 주지
않으며, 무작위 보상을 쓰지 않으므로 확률 공개 대상이 아니다.

판 진행 중 광고는 0 건이다. 사내 역분석에서 전면 광고가 플레이 단위를 끊고 외부 스토어로
전환시키는 사례가 직접 관찰됐기 때문이다(SRC-001).

## 라이브옵스 캘린더

상시 운영 인력을 전제하지 않는다. 운영 작업은 자동화되거나 주 단위 정산 한 번으로 끝나야 한다.

| 주기 | 작업 | 사람 개입 |
| --- | --- | --- |
| 상시 | 코스 생성과 검증 | 없음. 코드가 처리 |
| 상시 | 상대 기록 갱신 | 없음. 이용자 플레이가 갱신 |
| 주 1회 | 리그 정산 | 없음. 자동 정산 |
| 월 1회 | 고정 전략 승률 회귀 검사 | 결과 확인만. 이상 시 난이도 테이블 조정 |
| 분기 1회 | 코스메틱 파생 추가 | 선택 작업 |

확률형 상품이 없으므로 확률 공개 운영 부담이 없고, 실시간 랭킹 운영이 없으므로 상시 감시가 없다.

## 시뮬레이션 증거

대표 코호트 3개의 시간축이다. 기준선은 추정이 아니라 사내 BigQuery 실측이다.
`lizard-tycoon` 이 2026-09-17 기준 DAU 102, 코호트 517명에서 D1 28.2% / D3 16.2% / D7 12.0% 다.

| 코호트 | 성격 | D1 | D7 | D30 | 일 세션 | 세션당 판 | 깃털/일 | 30일 누적 깃털 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A 스침 | 온보딩 후 1~2세션 | 이탈 | 이탈 | 이탈 | 1 | 2 | 16 | 32 |
| B 습관 | 하루 한두 번 | 잔존 | 잔존 | 잔존 | 2 | 3 | 78 | 2,340 |
| C 몰입 | 대역 상승 추구 | 잔존 | 잔존 | 잔존 | 4 | 5 | 190 | 5,700 |

코호트 B 는 30일 안에 깃발 무늬 15종 상당을 해금할 수 있다. 코스메틱 총량을 그보다 넉넉히
두어 목표가 조기에 소진되지 않게 한다. 코호트 C 는 60일 무렵 대역 5 에 도달하며, 그 이후의
목표는 리그 순위와 코스메틱뿐이다. 전력 상승이 없으므로 이탈이 곧 손해가 되지 않는다.

**진행 벽**은 두 곳에 의도적으로 둔다. 대역 3(15승)과 대역 4(40승)이다. 승수 조건이므로
시간을 들이면 반드시 넘을 수 있고 과금으로 건너뛸 수 없다.

**악용 경로**와 대응은 다음과 같다.

| 악용 | 대응 |
| --- | --- |
| 일부러 져서 낮은 대역에 머무르기 | 대역은 하향하지 않는다. 깃털 보상도 대역에 비례하지 않는다 |
| 기록 조작으로 유리한 상대 만들기 | 기록은 선택 시퀀스만 담고 결과 수치를 담지 않는다. 결과는 재생 시 규칙이 다시 계산한다 |
| 자동 입력으로 최적 선택 반복 | 고정 전략 승률 상한(60%)이 구조적으로 이를 막는다. 최적 전략이 존재하지 않는 것이 밸런스 목표다 |
| 무한 재도전 | 보상 광고 재도전은 판당 1회, 일 3회 상한 |

**서버 비용 산정.** 판당 원격 연산은 쓰기 1건, 읽기 1건이다(AC-006). 무료 등급 일일 할당량은
읽기 50,000건, 쓰기 20,000건, 저장 1GiB 다(SRC-007).

| DAU | 1인 10판 기준 일 쓰기 | 일 읽기 | 무료 한도 대비 | 월 비용 |
| --- | --- | --- | --- | --- |
| 100 | 1,000 | 1,000 | 쓰기 5% | 0 |
| 1,000 | 10,000 | 10,000 | 쓰기 50% | 0 |
| 2,000 | 20,000 | 20,000 | 쓰기 100% | 0 |
| 3,000 | 30,000 | 30,000 | 쓰기 150% | 1 미만 |

저장은 기록 1건이 수백 바이트이고 **사람당 문서 1건을 덮어쓰므로** 총량이 이용자 수에
비례하되 판 수에는 비례하지 않는다. DAU 2,000 기준으로도 1GiB 한도에 한참 못 미친다.
무료 등급에 TTL 삭제가 포함되지 않으므로 오래된 기록을 TTL 로 지우지 않고 덮어쓰기로
처리한다(DEC-004). 상시 인스턴스가 없으므로 유휴 비용이 0 이다.

## 원격 설정

원격 설정으로 조정 가능한 항목과 불가능한 항목을 구분한다. 조정 가능 항목은 값이 바뀌어도
저장 호환성이 깨지지 않아야 한다.

| 항목 | 조정 가능 | 기본값 | 비고 |
| --- | --- | --- | --- |
| 난이도 테이블(수치 범위) | 가능 | 위 밸런스 표 | 월 회귀 검사 결과로만 조정 |
| 대역 해금 승수 | 가능 | 3 / 15 / 40 / 80 | |
| 깃털 획득량 | 가능 | 승 10 / 패 3 / 무 5 | |
| 보상 광고 일 상한 | 가능 | 3 | |
| 봇 폴백 활성 | 가능 | 켜짐 | 기록 풀이 충분해지면 비율을 낮춘다 |
| 반감 계수 | 불가 | 0.5 | 코어 규칙. 원격으로 바꾸면 기존 기록의 재생 결과가 달라진다 |
| 게이트 종류와 해소 순서 | 불가 | `02-gdd.md` 기준 | 같은 이유 |
| 코스 생성 알고리즘 | 불가 | | 같은 이유 |

재생 결과에 영향을 주는 값은 원격으로 바꾸지 않는다. 바꾸면 과거 기록으로 만든 대국이 원본과
다른 결과를 내어 AC-005 가 깨진다. 규칙 변경이 필요하면 기록 형식에 버전을 붙이고 구 버전
기록은 해당 버전 규칙으로 재생한다.
