# Crowd Gate Duel Google Play 출시 기록

공개 출시는 아직 완료되지 않았다. 승인 범위는1.0.0, versionCode1, com.seoleeapps.crowdgateduel, Seolee Apps, 대상13세 이상, 영어와 한국어, 지원 가능한 국가 전체와100% 공개다.

## 구현과 개발 검수

필수 수동 튜토리얼6단계, 오답 재시도와 이어하기, 완료 보상 중복 방지, 오프라인 봇 대전, 난이도와 꾸미기, 저장 복구, 특수 게이트 첫 안내, 설정의 재학습 및 개인정보 선택을 구현했다. 정수 판정과 Pcg32를 유지하고 원격 기록과 서버 상태 경로를 제거했다.

일반 대국은 결과와 보상을 먼저 저장하고 준비된 전면광고만 결과당 한 번 시도한다. 늦게 준비된 광고는 다음 판으로 넘기며 닫힘 뒤45초 간격을 별도 로컬 파일에 보존한다. 튜토리얼, 대국 중, 시작 및 복귀 때는 표시하지 않는다. Android 플러그인은 AdMob25.5.0, UMP4.0.0, API36, 최소 API24와 결과 카드 공유를 연결했다. 개발 환경 대체 구현의 통과는 실제 SDK 동작 증거와 구분한다.

후보0e70326b0ef541dd52f84096c0d9c76adfb68eb0에서 Godot CI39522362402와 Android CI39522362584가 통과했다. 단위275개, 코스10000개, headless와4개 렌더링 여정 각각279검사를 포함한다. [5회차 독립 검수](design/2026-10-21-offline-play-launch/iteration-5-result.md)도 같은 후보의 기능과UX를 통과했다. 1~4회차의 실패와 해결 근거는 보고서에 보존하며, 승인 없이6회차를 시작하지 않는다. 이후 네이티브 광고 콘텐츠 상한G 변경은 새 후보의 Java CI로 확인한다.

스토어 이미지16개는 실제 개발 화면과 기존 아이콘으로 만들고 규격 검사를 통과했다. 실제 사용자 이해도, 이탈률과 기기 실행은 확인하지 않았다. 이전 디버그 APK93MB는80MB 예산을 초과했으며 출시 AAB 또는 출시 크기 통과로 기록하지 않는다.

## 등록과 서명

[실제 Console 등록 기록](play-registration-2026-10-21.md)에 계정과 앱, 광고 ID, 전용 업로드 키와 백업 및 복원 결과를 보존했다. Play 앱4972940845333469610은 Seolee Apps 개인 계정5547060480954653351에 생성했다. 개인정보처리방침과 광고, 접근 제한, 대상 연령 등의 신고를 저장했다. IARC 상태는 완료됐으나 인증 ID는 `-`이다.

AdMob 앱과 전면광고를 만들고 운영 ID를 설정했다. app-ads.txt의 실제 게시자 항목을 확인했다. 앱 승인 상태는 검토 필요이며 공개 스토어 연결과 실제 광고 동작 확인이 남아 있다. 유럽 메시지 편집기가 상위 화면에 열려 있음을 확인하고 전용 유럽 및 미국 주 메시지를 게시했다. 각 목록을 새로고침해 게시됨을 읽었다. 기존 메시지는 변경하지 않았다. 실제 UMP 표시는 아직 확인하지 않았다.

업로드 키는 이 앱 전용으로 생성해 로컬 카탈로그에 등록했다. 로컬과 BeeStation의 새 키 포함5963개 파일 복원 검사를 각각 통과했다. GitHub google-play-release 환경은 출시 태그만 허용하며 키의 실행 복제본을 등록했다. 공유 Publisher는 기존 identity를 재사용한다. 새 앱 접근 권한은 실제 API 작업 전에 확인한다.

한국어와 영어 개인정보처리방침은 공식 사이트 PR82, 배포39453671353, SHA8ae005ba75ae8d60b9e0abcfce59c1b59a265f77에서 배포했다. 두 공개 URL의 HTTP200과 제품별 내용을 읽었다.

## 남은 출시 단계

| 상태 | 결과 |
|---|---|
| 기능과 화면 개발 검수 | 위 후보에서 통과, 광고 콘텐츠 상한G 이후 PR 및 main CI도 통과 |
| Play 앱 생성과 기본 신고 | 데이터 안전, 영어 및 한국어 등록까지 저장 완료 |
| IARC | 완료 표시, 인증 ID 미표시 |
| 운영 AdMob 연결 | ID 및 UMP 메시지 등록, 앱 승인과 송출 미확인 |
| 출시 서명 AAB | 미생성 |
| Play 내부 업로드 | 미실행 |
| 실제 UMP, 광고 표시 및 닫힘, Android 공유창 | 기기 승인 전 미실행 |
| 심사 접수, 승인, 공개와 스토어 버전 확인 | 각각 미실행 |

서명 빌드는 main에 포함된 annotated 출시 태그와 source-sha, version-name, android-version-code receipt, 같은 후보의 중앙 before-build 검사를 통과한 뒤 수행한다. 공개 PR에는 비밀값을 제공하지 않는다. 생성한 AAB의 패키지, 버전, 인증서, API와16KB 정렬을 검사하고 내부 업로드한다. 심사 직전 before-release 검사를 별도로 수행한다.

기기 사용은 후보 빌드와 개발 환경에서 확인할 수 없는 필수 항목, 시간 및 데이터 영향을 구체화한 뒤 별도 승인받는다. 현재 기기나 설치 앱을 조회하지 않았다.

브라질의 최신 연령 정보 수신 요건에 따라 첫 출시 제외 또는 연결 추가를 사용자에게 질문했다. 응답 전 국가 목록을 확정하거나 공개하지 않는다.

## 첫 서명 빌드 시도

v1.0.0 태그는1255be70ce86932160928bbfe91d40a85e31fdbb, versionCode1에 고정했다. 같은 SHA의 전체 CI39527023026 및 Android CI39527023064와 중앙 before-build L3 검사를 통과했다. [빌드39527740489](https://github.com/seoleeapps/crowd-gate-duel/actions/runs/39527740489)는 SDK 도구 준비에서 `sdkmanager: command not found`로 실패했다. 서명 키 단계는 미실행이고 AAB는 생성 및 업로드되지 않았다. 태그와 실패 로그는 보존했다.

Android 도구를 워크플로가 직접 설치하고 PR Android 검사에서도 같은 도구의 실행을 확인하도록 보완한다. 앱 소스와 제품 동작은 바꾸지 않는다. 이 수정은 첫 출시 구현에서 발견한 빌드 환경 결함의 범위다. 다음 후보는 새 태그를 사용하며 기존 태그를 옮기지 않는다.

새 임시 checkout에서 중앙 검증기의 의존성이 없으면 `ERR_MODULE_NOT_FOUND`로 실패했다. `npm ci --prefix` 설치도 잠금 파일 검사에서 실패했으며, 중앙 checkout을 작업 디렉터리로 지정한 `npm ci --ignore-scripts --no-audit`와 실제 검증기 모듈 import는 통과했다. 설치 통과를 먼저 기록했던 문장은 이 실행 결과로 정정했다. 출시 워크플로에 Node24.16.0과 같은 작업 디렉터리의 의존성 설치를 명시했다.
